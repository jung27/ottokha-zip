## 미해결 사항

### QA-01 · 높음 · 등기부 읽기 미니게임 전체 누락

원문은 ‘잔금일 하루’ 다음에 등기부 전체 화면에서 6곳을 클릭하도록 한다. 소유자 이름, 소유권 이전 날짜, 신탁 표기, 근저당 설정 날짜, 채권최고액, 근저당권자가 대상이다. ‘어제 설정된 근저당’이 정답이며, 채권최고액에는 계산 화면, 정답에는 계약 해지 설명이 있어야 한다.

현재 진행 순서는 `timing → settlement → insurance/defect → moving`이다. 가계약금 단계의 간단한 등기부 표는 존재하지만 이 미니게임과 계산 화면은 없다. 모든 11개 조합에 해당한다.

- 고시원 가계약금은 공통 원문 100만 원 대신 해당 유형 보증금인 10만 원으로 보정되어 있다.
- 전세 오피스텔은 월세 할인 대신 보증금 할인 대사로 바뀐다. 월세 빌라는 원문에 전세 전용으로 제시된 깡통전세 장면 대신 시세 비교 장면을 사용한다.
- 잔금 시점 확인을 건너뛴 전세 루트는 ‘전입신고와 확정일자를 마쳤다’고 단정하지 않고 확인이 필요하다고 표시한다. 이전 선택과 대사의 모순을 줄이는 보정이다.
