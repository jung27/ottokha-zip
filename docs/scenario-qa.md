## 후속 요청: 정답 확인 후 진행

아래의 기존 시나리오 대조 결과에 이어, 사용자의 최신 요청을 우선해 선택 흐름을 변경했다. 원문의 ‘오답이어도 다음으로 진행’과 기존 정답 결과 팝업은 이 요청으로 대체한다.

- 오답 경고에는 ‘다시 선택’만 표시한다. 경고를 닫거나 Escape를 눌러도 같은 선택 화면에서 다시 고르며, 앞선 대사를 반복하거나 다음 장면으로 이동하지 않는다.
- 시도한 오답은 회색으로 비활성화한다. 남은 정답을 고르기 전에는 진행할 수 없으며, 다음 단계 처리에서도 이 조건을 검사한다.
- 정답 선택지는 초록색과 체크 표시로 남긴다. 대화창에 초록색 굵은 글씨 ‘잘 하셨습니다’, 줄바꿈 두 번, 잘 확인한 부분을 짚는 문장과 기존 설명을 표시한다. 기존 결과 내용은 리뷰에도 유지한다.
- 정답 설명의 ‘다음’을 누르면 ‘다음 단계로 넘어갑니다.’를 약 1.6초 보여준 뒤 이동한다. 중복 클릭이나 이전 장면의 지연 호출로 단계를 건너뛸 수 없다.
- 확인 항목의 경고도 재선택만 제공한다. 재선택하면 체크한 항목을 유지하며, 경고 원인을 바로잡은 뒤 진행한다. 임장 전체 확인 조건도 유지한다.
- 오답을 고친 뒤에도 처음 시도한 오답과 누락 항목은 리뷰의 위험 기록에 남긴다. 현재 장면의 경고는 다시 띄우지 않는다.
- 집 유형 화면의 ‘이전’은 월세·전세 계약 방식 선택으로 돌아가며, 선택한 계약 방식도 유지한다.

자동 검사 54개, 빌드와 린트를 통과했다. 월세 6개·전세 5개 조합의 33개 경로는 오답을 정답으로 수정한 뒤 엔딩에 도달하도록 검사한다. 연속 오답의 재선택 차단, 재시도 이력, 전체 정답 설명, 체크 항목 재선택과 경고 해소 조건을 추가로 검증했다.

브라우저에서는 월세·전세 각각의 이전 버튼, 같은 장면에서 오답 재선택, 연속 오답의 회색 비활성화, 정답의 초록색 유지, 굵은 칭찬 문구와 두 번의 줄바꿈, 전환 안내 후 자동 이동을 확인했다. 모바일과 다크 모드에서도 정답 표시를 확인했다.

전세 원룸의 임장 13곳을 확인한 뒤 대리권 선택과 특약 화면까지 진행했다. 특약을 비우거나 일부만 넣으면 경고에 ‘다시 선택’만 표시되고, 다시 고를 때 기존 체크와 현재 선택 화면이 유지된다. 경고를 해소하면 서명 장면으로 이동하며, 새로고침 시 시작 화면으로 초기화되는 것도 확인했다.

## 새 접속 시 처음부터 시작

- 진행 기록을 읽고 쓰던 localStorage 코드와 저장 기록 복원·이전 버전 보정 코드를 제거했다.
- 새 게임은 항상 시작 화면, 빈 선택 기록, 빈 임시 체크 목록으로 만들어진다.
- 예전 링크에 `#inspection`이나 `#ending`이 붙어 있어도 새 접속 시 `#home`으로 바뀐다.
- 새로고침하면 진행 기록이 초기화된다. 브라우저의 뒤로 가기 캐시로 재방문한 경우도 새로 불러오도록 처리했다.
- 테마와 소개창 확인 여부도 브라우저에 저장하지 않는다.
- 페이지를 닫거나 새로고침하지 않은 동안에는 메모리에서 진행한다. 같은 실행 안에서 첫 화면에 갔다가 ‘이어서 하기’로 돌아오는 기능은 유지한다.

## 원문과 구분한 기존 보정·구현 방식

- ‘집으로 고르는→집을 고르는’, ‘관리바→관리비’, ‘새 방의 자격→가격’은 오타 교정이다.
- 고시원 가계약금은 해당 유형 보증금인 10만 원으로 보정한다.
- 전세 오피스텔은 월세 대신 보증금 할인 대사를 사용한다. 월세 빌라는 전세 전용 깡통전세 장면 대신 시세 비교 장면을 사용한다.
- 잔금 시점 확인을 건너뛴 전세 루트는 전입신고와 확정일자를 마쳤다고 단정하지 않는다.
- 등기부는 글자와 클릭 영역을 선명하게 표시하기 위해 이미지 파일 대신 서류 형태의 화면으로 구현했다. 날짜와 금액은 연습용 가상 사례이며, 원문의 여섯 영역·설명·계산·정답 경고를 구현했다.
- 성공 엔딩의 기뻐하는 인물은 SVG 일러스트로 표현했다.
